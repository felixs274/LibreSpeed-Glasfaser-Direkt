# LibreSpeed-Glasfaser-Direkt

Eine benutzerdefinierte [librespeed-cli](https://github.com/librespeed/speedtest-cli) Serverliste für [Glasfaser Direkt](https://glasfaser-direkt.de/).

## Verwendung
```bash
librespeed-cli --server-json https://raw.githubusercontent.com/felixs274/LibreSpeed-Glasfaser-Direkt/refs/heads/main/servers.php
```
